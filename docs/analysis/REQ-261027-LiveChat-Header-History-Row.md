# REQ-261027 — 라이브챗 대화방 헤더: 이전 대화·통합 줄 분리·강조

## 요구사항
> https://shoptalk.amoeba.site/live-chat 대화방 헤더
> "이 고객의 이전 대화 00건 | 통합 0건" 앞에서 줄바꿈하고, 이 고객의 이전 대화 | 통합 0건 ← 버튼 및 이 라인 강조(배경색)

## AS-IS
`apps/web/src/domain/live-chat/LiveChatPage.tsx` 대화방 헤더는 2줄(REQ-260825 R3)이다.
- 1줄(정보): 세션 이름 · 상태 · 자동응답 · AI 배지 · 신원 배지 · 상담카테고리 · **[기업] 배지 + "이 고객의 이전 대화 N건 ▸"**(`CompanyThreadButton`) · **"통합 N ▾" 배지 또는 [같은 고객 대화 통합 (N)]**(`MergeRoomControl`) · 담당자
- 2줄(액션): 찾기 · 고정 · …

문제
- 이전 대화와 통합 진입점이 1줄 정보 배지 사이에 섞여 `flex-wrap`으로 줄 중간에서 끊긴다. 위치가 화면 폭에 따라 달라진다.
- "이전 대화 N건"은 작은 텍스트 링크(`text-xs`, 밑줄은 hover 때만)라 버튼으로 보이지 않는다(10/23 "버튼 안 보임" 보고 참고).

## TO-BE
- 이전 대화와 통합 두 진입점을 1줄에서 빼서 **바로 아래 독립된 줄**로 둔다.
- 그 줄에 **배경색**을 깔아 강조하고, 두 진입점을 **버튼 형태**로 만든다. 사이는 `|`로 구분한다.
- 두 진입점이 모두 없는 대화(게스트, 후보 없음)에서는 줄을 그리지 않는다.

## 갭

| G3 | [기업] 배지가 `CompanyThreadButton` 안에 묶여 있음 → 정보 배지라 1줄에 남겨야 함 |

## 제약
- UI만 변경한다. API·스키마 변경은 없다.
- 문구는 기존 i18n 키를 쓴다. 새 키가 필요하면 6개 언어에 모두 추가한다.
- 모달 동작(체크·통합·자동 추가)은 바꾸지 않는다.

# REQ-261027 — 위젯: 닫기(X) 때 상담 피드백 안내

## 요구사항 (2026-10-27)
고객이 위젯 헤더의 닫기 버튼을 누르면 상담 피드백을 남기도록 안내한다.
- 문구: "상담피드백을 남기시면 서비스 개선에 도움이 됩니다."
- [승낙] → 피드백(만족도) 화면을 보여준다.
- [그냥 닫기] → 상담을 종료하고 닫는다.
- [앞으로 안 보기] → 이후 피드백 안내를 띄우지 않는다.

## AS-IS (`apps/widget`)
- 헤더 X(`WidgetPanel.dismiss`)는 패널만 닫는다(앱 모드는 호스트에 닫기 요청). 대화는 계속 열려 있다.
- 트리거 모드(스토어 헤더 요소로 여는 방식)의 데스크톱에서는 X가 없다. 바깥 클릭과 Esc는 로더가 닫는다. 모바일(compact)에서는 X가 있다.
- 만족도 카드 `CsatCard`(테넌트 `csat_mode`: rating = 별점, survey = 해결 여부 → 별점 → 사유)는 `canRate`일 때 대화 화면 안에 나온다. 서버는 **종료된 대화(24시간 안)**나 자동 마무리의 평가 요청 상태에서만 평가를 받는다.
- 고객이 직접 끝내는 [상담 종료](`endChat`)는 대화 화면 안의 확인 줄에서만 할 수 있다. 끝나면 `ended`가 되고, 다음 메시지가 새 대화를 시작한다.
- 대화 상태(`useChat`)는 대화 탭 안에 있어서 헤더(WidgetPanel)는 대화가 진행 중인지 모른다.

## TO-BE
- 진행 중인 대화가 있을 때 X를 누르면 패널을 닫기 전에 안내 카드를 띄운다.
- [피드백 남기기]: 상담을 종료하고 대화 탭에서 만족도 카드를 보여준다(패널 유지). 평가 후 감사 메시지가 나오고, 다음 X는 바로 닫힌다.
- [그냥 닫기]: 상담을 종료하고 패널을 닫는다.
- [앞으로 안 보기]: 이 브라우저에서는 다시 묻지 않고, 지금은 그냥 닫기와 같게 처리한다(종료 + 닫기).
- 다시 묻지 않기로 했거나 안내 조건이 아니면 X는 지금처럼 바로 닫는다(대화 종료 없음).

## 제약
- 상담원 연결 대기 중(`waiting`)인 고객을 X 한 번으로 대기열에서 빼면 안 된다.
- 피드백은 기존 만족도 카드와 서버 규칙(종료된 대화만 평가)을 그대로 쓴다. 새 평가 저장소는 만들지 않는다.
- 문구는 i18n 6개 언어. 위젯 언어를 따른다.

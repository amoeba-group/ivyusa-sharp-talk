# REQ-261028: 상담원 응대 메시지에 이름·프로필 아이콘 표시 + 마이페이지 프로필 아이콘 업로드

- 참조: 사용자 제공 스크린샷 `Screenshot 2026-10-28 at 9.43.53 AM.png`(go2joy 위젯, AI "JoyBot - AI Operator" 다음에 사람 상담원 메시지 "Go2Joy Support" + 사람 아이콘)
- 요구사항 원문

## 1. AS-IS

### 위젯의 상담원 메시지 (`apps/widget/src/components/chat/MessageBubble.tsx`)
| 디자인 | 이름 | 아이콘 |
|---|---|---|
| 아바타 줄(`design.messageStyle='avatar'`, 스테이징 기준 go2joy만 사용) | 테넌트 공통 호칭 `widgetCopy.agentSenderName`이 있으면 **그것이 실명보다 우선**한다(go2joy: "Go2Joy Support"). 없으면 `users.name`을 쓴다 | 테넌트 공통 `design.icons.agentAvatar`가 쓰이고, 없으면 기본 사람 아이콘을 쓴다. go2joy는 미설정이라 기본 아이콘이 나온다 |
| 기본(그 외 테넌트) | 말풍선 위에 회색 작은 글씨로 `users.name`을 표시한다. 이름이 없으면 아무것도 표시하지 않는다 | 없음 |

- 메시지 응답 `ChatMessageResponse`에는 `senderName`만 있고 아이콘 정보는 없다. `senderName`은 `ChatService.resolveSenderNames`가 `users.name`에서 읽는다.
- 결과적으로 **어떤 상담원이 답했는지 고객이 구분할 수 없다.** 상담원마다 다른 얼굴을 줄 방법도 없다.

### 상담원 프로필
- 마이페이지(`apps/web/src/domain/my-page/MyPage.tsx`)에는 이메일, 역할, 워크스페이스, 라벨, 보안(비밀번호·MFA)만 있고, **이름이나 아이콘을 바꿀 곳이 없다.**
- `users` 테이블에 프로필 이미지 칼럼이 없다.
- **스테이징에서는 상담원 대부분의 `users.name`이 비어 있다**(테넌트별 사용자 수와 이름 없는 사용자 수: ivyusa 12명 중 11명, go2joy 12명 중 11명 등). 이름 표시를 켜도 지금은 보여줄 이름이 없다.
  - 프로덕션 데이터는 조회 권한 문제로 확인하지 못했다. 같은 상황일 가능성이 높다.

### 재사용 가능한 기반
- 테넌트 자산 저장소(`tenant_assets`, PLN-260910):
  - 파일은 `tenants/{id}/{area}/`에 저장한다.
  - 이미지 형식을 내용으로 검사하고 sharp로 다시 인코딩한다(메타데이터 제거).
  - 공개 경로 `/public/widget/asset/:uuid?v=`로 제공하며, 위젯에는 이미 `assetUrl()`이 있다.
- 다만 업로드 API(`POST /tenant-assets`)는 master와 director만 쓸 수 있고, `area=design`만 받는다.

## 2. TO-BE
1. 상담원이 마이페이지에서 **자기 프로필 아이콘을 올리고, 바꾸고, 지울 수 있다.** 고객에게 보일 **표시 이름**도 정할 수 있다.
2. 위젯에서 사람 상담원 메시지는 **그 상담원의 이름과 아이콘**으로 표시된다.
   - 아이콘이 없으면 테넌트 공통 상담원 아바타를 쓰고, 그것도 없으면 기본 사람 아이콘을 쓴다.
   - 이름이 없으면 테넌트 공통 호칭을 쓴다.
3. AI 메시지는 지금과 같다(봇 아바타와 AI 호칭).

## 4. 사용자 흐름
1. 상담원이 콘솔 > 마이페이지 > 프로필에서 [사진 올리기]를 누르고 이미지를 고른다. 업로드되면 미리보기가 바뀌고 토스트가 뜬다.
2. 같은 카드에서 표시 이름을 입력하고 [저장]을 누르면 토스트가 뜬다.
3. 그 상담원이 라이브챗에서 답장한다. 고객 위젯에는 상담원의 아이콘과 이름이 붙은 말풍선이 보인다.
4. 아이콘을 지우면 이후 위젯 표시가 테넌트 공통 아바타로 돌아간다. 이미 보낸 메시지도 다음 폴링 때부터 바뀐다(응답할 때마다 조회하기 때문).

## 5. 제약
- 개인정보: 위젯에 나가는 것은 표시 이름과 아이콘뿐이다. 이메일이나 이메일 앞부분을 이름 대신 보여주지 않는다.
- 아이콘은 공개 URL(uuid)로 제공된다. 테넌트 위젯 디자인 아이콘과 같은 보안 수준이며, uuid를 추측할 수 없다.
- 파일 검증은 내용 기반(PNG/JPG/WEBP)이다. SVG는 받지 않는다(스크립트 위험).
- 스키마 변경이 있으므로 SQL을 스테이징·프로덕션에 먼저 적용한 뒤 배포한다.

## 엣지·주의
- 찾기로 대화를 연 경우는 하단 이동보다 검색 결과 가운데 맞춤이 우선한다. 이전 대화 더보기는 위치를 바꾸지 않는다.
- 통합 대화방의 자동응답 라벨은 선택한 대화일 때만 AI 에이전트명을 붙인다(대화마다 다를 수 있음).
- 과거 수락 건은 active 배정이 겹쳐 있을 수 있다. 이력은 시간순으로만 보여주고, 겹침을 이관으로 해석하지 않는다.
- 연락처 수정은 reveal(감사)로 원문을 받은 뒤에만 열린다. 실패하면 폼을 열지 않는다(마스킹 값 덮어쓰기 방지).
- 백필된 플랫폼 표시명은 NULL이다(SQL에서 암호화 불가). 다음 동기화나 로그인 때 채워진다.

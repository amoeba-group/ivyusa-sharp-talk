## 3. 엣지 케이스
- 팀이 없으면 회색 "미지정", 라벨이 없으면 회색 "없음"으로 표시한다(줄은 그대로).
- 마스터가 팀이나 라벨을 바꾸면 다시 로그인하지 않아도 마이페이지에 반영된다(프로필 조회 캐시 5분, 페이지를 다시 열면 갱신).
- 안내 문구와 [사용자 관리] 링크는 사용자 결정에 따라 넣지 않았고, 권한도 바꾸지 않았다.

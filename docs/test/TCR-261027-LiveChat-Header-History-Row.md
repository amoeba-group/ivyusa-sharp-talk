## 엣지
- 줄 노출 판정은 CSS `has-[>button]:flex`로 한다(Tailwind 3.4). 두 컴포넌트가 스스로 null을 반환하므로 부모에서 다시 조회하지 않는다.
- 구분선은 첫 번째나 마지막 자식이 되면 `first:hidden last:hidden`으로 숨는다. 둘 다 있을 때만 보인다.
- 모달은 닫혀 있으면 `null`을 반환해서 줄의 자식으로 잡히지 않는다.

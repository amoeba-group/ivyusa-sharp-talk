## 결정 사항
| # | 결정 | 권장안 | 대안 |
|---|---|---|---|
| D1 | 줄 위치 | **정보 줄과 액션 줄 사이**에 독립된 줄 | 헤더 맨 아래(액션 줄 다음) |
| D2 | 강조 | **줄 배경 `bg-primary-50` + 테두리 `border-primary-100` + 둥근 모서리**, 두 진입점은 `Button size="sm" variant="secondary"` 모양 | 배경만 깔고 링크 모양 유지 |
| D3 | 건수 표기 | **기존 문구 유지**: "이 고객의 이전 대화 5건 ▸", "통합 3" | 건수를 빼고 "이 고객의 이전 대화"만 표시 |
| D4 | [기업] 배지 | **정보 줄에 남김**(신원 정보) — `CompanyThreadButton`에서 분리 | 강조 줄로 같이 이동 |
| D5 | 빈 줄 방지 | 줄 컨테이너에 `empty:hidden` — 두 컴포넌트가 모두 `null`이면 DOM 자식이 없어 줄이 사라짐(모달은 닫혀 있으면 렌더하지 않음 → 구현 시 확인) | 부모가 후보 조회를 따로 해서 판단(중복 조회) |
| D6 | 구분선 `│` | 두 진입점이 모두 있을 때만 CSS로 표시(두 번째 요소의 `border-l`) | 항상 표시 |

## 단계
1. `CompanyThreadButton` — [기업] 배지 제거(별도로 `LiveChatPage` 1줄에서 렌더), 진입점을 `Button` 모양 + 아이콘(`History`)으로 변경.
2. `MergeRoomControl` — 통합 배지/버튼은 그대로 두고, 줄 안에서 크기만 맞춤(필요할 때만).
3. `LiveChatPage` — 1줄에서 두 컴포넌트를 빼고, 그 아래에 강조 줄(`flex flex-wrap items-center gap-2 rounded-md border border-primary-100 bg-primary-50 px-3 py-1.5 empty:hidden`)을 추가. [기업] 배지는 1줄에 남김.
4. 검증: web tsc, `i18n:check`, `radius:check`(고정 `rounded` 금지 규칙 → 토큰 클래스 사용), 로컬 화면에서 4가지 경우 확인(기업+통합 전·기업+통합됨·개인 고객·게스트). 다크 모드가 있으면 그것도 확인.

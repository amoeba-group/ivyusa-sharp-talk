# PLN-261027 — 라이브챗: 사람 상담원 대응 이력 · AI 자동응답 끄기/넘기기

- REQ: `docs/analysis/REQ-261027-LiveChat-Staff-Takeover-History.md`
- 상태: **승인됨 (2026-10-27, D1~D7 권장안)**
- UI 영향: 있음 (대화방 액션 줄, 담당 이력 카드·전체 히스토리 모달)
- 스키마 변경: **없음** (기존 메시지·알람·감사 로그로 이력 구성, 자동응답은 기존 세션 설정 사용)

## 결정 사항
| # | 결정 | 권장안 | 대안 |
|---|---|---|---|
| D1 | 직접 대응 이력(G1) | 대화별·상담원별 **첫 답장 시각에 '상담원 대응' 이벤트**를 넣고 답장 수를 붙인다(예: "minh.le(Minh) 대응 · 답장 2"). 배정이 있는 상담원도 첫 답장을 따로 보여준다 | 답장마다 한 줄 |
| D2 | 호출·확인(G2) | 연결 요청 줄에 **호출 대상**(알람 target 사용자들)을 붙이고, 알람 확인을 **'요청 확인 · 아이디(이름)'** 이벤트로 넣는다. 대상 없는 알람(전체 호출)은 "전체 상담원 호출" | 요청 줄에 확인자만 |
| D3 | 표시 형식(G3) | 담당 이력 카드·모달의 상담원은 **아이디(이름)**: 아이디 = 로그인 이메일의 @ 앞부분, 이름이 있으면 괄호. 이름이 없으면 아이디만. 말풍선 등 다른 화면은 지금 그대로 | 전체 화면 통일 |
| D4 | AI 자동응답 끄기(G4, R2·R3) | AI가 답하고 있는 대화(사람이 수락하지 않음, 자동응답 켜짐)에 **[AI 자동응답 끄고 직접 대응]** 버튼. 누르면 그 세션의 자동응답을 끔(기존 세션 설정 `off`)으로 바꾸고, 이전 값을 감사 기록에 남긴다. 수락·배정은 하지 않는다 | 버튼이 수락까지 함께 수행 |
| D5 | 직접 답장 시 안내 | 자동응답이 켜진 대화에서 상담원이 답장을 보내면, 입력창 위에 **"AI가 계속 답하고 있습니다 — [자동응답 끄기]"** 한 줄 안내(자동으로 끄지 않음) | 답장하면 자동으로 끔 |
| D6 | 에이전트에게 넘기기(G5, R3) | 자동응답이 꺼져 있고 수락되지 않은 대화에 **[답변 완료 · AI에게 넘기기]** 버튼. 확인 창(기존 [AI로 반환]과 같은 설명과 고객 안내 미리보기)에서 진행하면 자동응답을 **끄기 전 값**으로 되돌리고 고객에게 기존 핸드백 안내를 보낸다. 수락된 대화는 기존 [AI로 반환] 그대로 | 안내 없이 설정만 되돌림 |
| D7 | 이력(G6) | 감사 `agent.session.auto_reply`를 이력으로: **'AI 자동응답 끔 · 아이디(이름)'**, **'AI에게 넘김 · 아이디(이름)'**(D6 경로), 그 외 설정 변경은 'AI 자동응답 설정 변경(자동/승인)' | 표시 안 함 |

자동응답을 끈 뒤 (수락 전)
[찾기] [핀 고정] [지정] [이슈로 등록] [싱크] [수락] [🤖▶ 답변 완료 · AI에게 넘기기] [종료]

수락한 대화(status=agent): 기존 [AI로 반환] 그대로

## 단계
1. **API**
   - `ConversationHandlersService`: 상담원 메시지(sender_type agent) 첫 답장·답장 수(D1), 알람 대상·확인(D2), 감사 `agent.session.auto_reply` 해석(D7, target `session:{세션}` + metadata conversationId).
   - 이름 해석은 `staffLabel(user)` = 아이디(이름)(D3).
   - 새 `POST agent/conversations/:id/ai-pause`: 이전 모드를 감사 metadata에 남기고 off로 바꿈(D4).
   - 새 `POST agent/conversations/:id/ai-resume`: 마지막 pause의 이전 모드로 되돌리고 핸드백 안내 메시지 발송(D6). 수락된 대화면 409(기존 [AI로 반환] 사용).
2. **웹**: 액션 줄 버튼 2종과 확인 창, 직접 답장 안내 줄, 헤더 배지, 이벤트 문구, i18n 6개 언어.
3. **테스트**: 직접 답장만 있는 대화의 이력, 알람 대상·확인, 아이디(이름) 형식, pause/resume(이전 모드 복원, 안내 발송, 수락된 대화 거부, 테넌트), 감사 해석. 로컬 화면 확인.
4. **배포**: 스키마 변경 없음 → 스테이징 → 프로덕션(승인 후).

## 사이드 임팩트
| 영역 | 영향 |
|---|---|
| 자동응답 설정 | pause는 세션 단위 설정을 바꾼다. 같은 세션의 다음 대화에도 적용되므로, 넘기기 때 이전 값으로 되돌린다. 넘기지 않고 대화가 끝나면 끈 상태가 남는다 → 헤더 배지로 보이게 한다 |
| 고객 안내 | 넘기기 때만 기존 핸드백 안내를 보낸다(끄기는 고객에게 알리지 않음) |
| 수락 흐름 | 바뀌지 않는다. 수락하면 기존처럼 AI가 멈추고 [AI로 반환]을 쓴다 |
| 이력 성능 | 카드는 대화 1건의 메시지 집계 1쿼리가 늘어난다. 방 전체 모달은 열 때만 |
